# E-Commerce Digital Marketing Portfolio Project

## Project
Digital Campaign Performance, Customer Insights & Growth Recommendations

**Target role:** Digital Marketing  
**Domain:** E-commerce / Retail  
**Difficulty:** Intermediate

## Important data disclosure
All CSV datasets and calculated results included here are synthetically generated for portfolio practice. They are not actual company data, and the survey responses are not real respondents. Do not describe the demo findings as actual market research. Use the Google Forms guide to collect genuine voluntary responses and replace the demo survey file.

## Files
- `campaign_performance.csv` - 90 days of daily campaign metrics (4 channels, 12 campaigns)
- `orders.csv` - synthetic order-level records
- `customers.csv` - synthetic customer profile table
- `google_forms_survey_template.csv` - question list and response options
- `demo_survey_responses_synthetic.csv` - synthetic responses for practicing analysis
- `Digital_Marketing_Analysis.xlsx` - workbook with data, KPI summary and channel chart
- `marketing_analysis_queries.sql` - SQL table definitions and 9 analysis queries (MySQL 8+)
- `marketing_analysis.py` - Python analysis and charts
- `Power_BI_Dashboard_Guide.txt` - data model, DAX measures and report layout
- `Google_Forms_Survey_Guide.txt` - instructions to create the primary research survey
- `Final_Project_Report.docx` - written report
- `Digital_Marketing_Portfolio_Presentation.pptx` - 10-slide interview presentation

## Step-by-step execution (one-day build)
1. Read the report and presentation (30-45 minutes).
2. Open the Excel workbook; inspect `KPI_Summary`, `Channel_Analysis`, `Order_Channel_Analysis` (45 minutes).
3. Run the Python script in the same folder after installing pandas and matplotlib (30 minutes).
4. Create a MySQL database, import the CSV files and run the SQL queries (60-90 minutes).
5. Create the Google Form using the guide. Share only with willing respondents; collect 50-100 responses over time (30 minutes setup; response collection takes longer).
6. Import the CSV files into Power BI and follow the guide to create four report pages (1-2 hours).
7. Customize the presentation with screenshots from your own dashboard and write a short reflection on what you learned (30 minutes).

## KPI definitions
- CTR = clicks / impressions
- CPC = spend / clicks
- Conversion rate = campaign orders / sessions
- CPA = spend / campaign orders
- ROAS = campaign-attributed revenue / ad spend
- AOV = delivered net revenue / delivered orders

## Suggested portfolio story
Business problem -> data sources -> KPI definitions -> channel comparison -> customer insights -> recommendations -> experiments -> limitations.
